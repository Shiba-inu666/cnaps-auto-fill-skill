# 表格快速处理

## 只识别两列

每张工作表只扫描表头，定位以下两类字段：

- 开户行：`开户行`、`收款账号开户行`、`收款方开户行名称`、`开户行支行名称`
- 行号：`行号`、`人行行号`、`联行号`、`收款银行人行行号`、`收款方联行号`、`大额行号`、`开户行大额行号`

定位后立即固定列索引。此后只访问这两列的数据单元格，不读取其他列。无法唯一识别时停止该工作表并提示，不猜列。

## 批量补全与核对

1. 读取行号列，并读取每行对应的开户行名称；不访问其他列。
2. 对开户行名称去重后批量查询注册库；相同名称只处理一次。
3. 行号为空：只把 `auto_fill_ready` 的 12 位行号作为文本写入。
4. 行号已有值：转为文本并去除首尾空格后，直接与 `auto_fill_ready` 的核验值比较，结果记为 `正确` 或 `不一致`；不单独检查位数或格式。
5. 本地库无法给出确定映射时按来源规则核验；仍无充分证据则记为 `无法确认`，不得判断为正确或错误。
6. 不一致的已有行号默认保留，只在用户明确要求自动更正时以核验值替换。
7. 未解析或冲突的空白项保持空白；安全的上级行兜底必须标记为 `parent_fallback`，不能当作具体网点精确匹配。
8. 默认另存新文件。复查时仍只读取开户行和行号两列，核对补全数、正确数、不一致数和无法确认数。

除非用户明确要求，不创建审计工作表。交付回复只列不一致、无法确认及其他问题行。
